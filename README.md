- [Choosing S3 compatible storage for backups on a budget](choosing-s3-compatible-storage-for-backups-on-a-budget.md): Comparing object storage options for database dumps and file backups from a small VPS.
- [Database migrations during deploys: where and when to run them](database-migrations-during-deploys-where-and-when-to-run-them.md): Patterns for running schema migrations safely when deploying containerized apps.
- [Port mapping or reverse proxy: exposing several apps from one server](port-mapping-or-reverse-proxy-exposing-several-apps-from-one-server.md): Why publishing many container ports gets messy and how a reverse proxy simplifies multi-app servers.
